## About

FOSStober 2026 is a month-long, fully online open-source contribution event, in the spirit of Hacktoberfest. It runs from 1 October through 31 October 2026.

Maintainers can list projects until 21 October, 11:59 PM IST. Each project must include `README.md` and `CONTRIBUTING.md`, with the open issues written in one of those files. Contributors from any region pick those issues, open pull requests, and get them merged. A live leaderboard tracks project progress and individual contributions as they happen.

You contribute to projects other people listed. Pull requests on a project you maintain do not count.

Join the ONLY FOSS [Discord](https://discord.gg/CXNustDut3) and stay updated there for listings, schedule changes, and announcements.

## Schedule

- **Registration** — Closes 21 October, 11:59 PM IST.
- **1 October, 12:00 AM IST** — Contributions open.
- **21 October, 11:59 PM IST** — Last time to list a project.
- **1–31 October** — Contributors work. Leaderboard updates live.
- **31 October, 11:59 PM IST** — Window closes. Winners from the leaderboard.

## Rules

- Open to contributors and maintainers worldwide.
- Register first. The form asks for basic information, then whether you are joining as a Project Maintainer or a Contributor.
- Maintainers add their own projects until 21 October, 11:59 PM IST. Each project must include `README.md` and `CONTRIBUTING.md`. The issues open for contribution must be written in one of those files. Projects cannot be added after that time.
- Contributors work only on projects listed by other maintainers.
- Pull requests to your own project do not count toward the leaderboard.
- Only merged pull requests count for contributors. Only closed issues on listed projects count for the project ranking.
- Be kind. Follow the ONLY FOSS Code of Conduct.
- Maintainers decide what merges. Quality over spam.

## Prizes

### Most issues closed
First place among listed projects. The project that closes the most issues during October.

### Project runner-up
Second place among listed projects, by issues closed.

### Most pull requests merged
First place among contributors. The person with the most merged pull requests during October.

### Contributor runner-up
Second place among contributors, by merged pull requests.

## Rewards

### Project track
The first-place project and the runner-up each receive a reward at the end of the month. Ranking is by issues closed on the live leaderboard.

### Contributor track
The first-place contributor and the runner-up each receive a reward at the end of the month. Ranking is by merged pull requests on the live leaderboard.

## Important notes

- Self-contributions are excluded. A pull request on a project you maintain does not count for you or as a qualifying contribution on that project.
- The leaderboard is the record. It shows contributor activity and project pull requests in real time.
- Deadlines are in IST. Registration and project listing close on 21 October at 11:59 PM IST. The contribution window closes on 31 October at 11:59 PM IST.
- A listed project must contain `README.md` (overview, setup, and usage) and `CONTRIBUTING.md` (how to contribute). Open issues must be written in one of those files. Projects missing either file, or with no issues listed, are not open for the sprint.
- Stay updated on the ONLY FOSS [Discord](https://discord.gg/CXNustDut3). That is where listings, schedule changes, and announcements are posted. GitHub is the source of truth for code.
- Announcements use IST (Asia/Kolkata) unless noted otherwise.

## FAQ

### Who can join?
Anyone, worldwide. You do not need to be a student, and you do not need prior open-source experience.

### How do I register?
Use the Register button before 21 October, 11:59 PM IST. The form asks for your basic information first, then whether you are joining as a Project Maintainer or a Contributor.

### What does a maintainer submit?
A project that includes `README.md` and `CONTRIBUTING.md`. `README.md` covers what the project is, how to set it up, and how to use it. `CONTRIBUTING.md` covers how to contribute. The issues open for contribution must be written in one of those two files. A project link alone is not enough.

### When can maintainers add a project?
Until 21 October 2026, 11:59 PM IST. Listing is open before 1 October, and that is the cutoff.

### Can I contribute to my own project?
No. Pull requests on a project you maintain do not count. Contribute to projects listed by other maintainers.

### Do I need my own project?
No. Contributors only need to register and work on listed projects. Only maintainers add projects.

### How does the leaderboard work?
It updates in real time. Projects are ranked by issues closed. Contributors are ranked by merged pull requests.

### What do winners get?
Two tracks, each with a first place and a runner-up. Projects: most issues closed. Contributors: most merged pull requests. Those four places receive rewards when the month ends.

### When does it run?
Contributions run from 1 October 2026, 12:00 AM IST, through 31 October 2026, 11:59 PM IST. Maintainers can list projects until 21 October, 11:59 PM IST. It is fully online.

### Where do I stay updated?
Join the ONLY FOSS [Discord](https://discord.gg/CXNustDut3). Project listings, schedule changes, and announcements for FOSStober 2026 are posted there.
